# Contribution Guidelines

Thank you for considering contributing to **Awesome Reverse-Engineered Games**!

## How to Contribute

1. Fork this repository.
2. Add your suggested game or reverse-engineering project in the appropriate section.
3. Ensure the project is maintained, documented, and includes references/tools used.
4. Keep entries concise (<100 words), objective, and well-formatted.
5. Submit a Pull Request with a clear description of your addition.
