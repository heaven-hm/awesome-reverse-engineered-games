## Repository Overview
`awesome-reverse-engineering-games-ai` is a curated knowledge base, research repository, and guide system for AI-assisted video game reverse engineering, decompilation, memory analysis, binary format reconstruction, and engine preservation.

## Guidelines
- All documentation files in this repository must be clean, structured Markdown (`.md`).
- Focus on practical workflows combining LLMs / AI agents with binary analysis tools (Ghidra, IDA Pro, x64dbg, Cheat Engine, Radare2).
- Keep reference guides modular and well-cross-referenced.
