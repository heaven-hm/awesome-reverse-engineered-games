# Awesome Reverse-Engineered Games [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

Open-source decompilation projects that reconstruct the source code and behavior of classic video games.

## Contents

- [Projects](#projects)

## Projects

- [Super Mario 64](https://github.com/n64decomp/sm64#readme) - Community-led decompilation of the Nintendo 64 game.
- [The Legend of Zelda: Ocarina of Time](https://github.com/zeldaret/oot#readme) - Decompilation of the Nintendo 64 action-adventure game.
- [The Legend of Zelda: Majora's Mask](https://github.com/zeldaret/mm#readme) - Decompilation of the Nintendo 64 action-adventure game.
- [Pokémon Red and Blue](https://github.com/pret/pokered#readme) - Disassembly of the original Game Boy role-playing games.
- [Pokémon Crystal](https://github.com/pret/pokecrystal#readme) - Disassembly of the Game Boy Color role-playing game.
- [Pokémon Emerald](https://github.com/pret/pokeemerald#readme) - Decompilation of the Game Boy Advance role-playing game.
- [Pokémon Platinum](https://github.com/pret/pokeplatinum#readme) - Decompilation of the Nintendo DS role-playing game.
- [Sonic the Hedgehog](https://github.com/sonicretro/s1disasm#readme) - Disassembly of the original Sega Genesis game.
- [Sonic the Hedgehog 2](https://github.com/sonicretro/s2disasm#readme) - Disassembly of the Sega Genesis platform game.
- [Sonic the Hedgehog 3 & Knuckles](https://github.com/sonicretro/skdisasm#readme) - Disassembly of the combined Sega Genesis platform game.
