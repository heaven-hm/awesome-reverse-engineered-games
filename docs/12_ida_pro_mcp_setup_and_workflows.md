# 12. IDA Pro MCP Server: Setup, Integration & Workflows

## Overview

**IDA Pro** remains the gold standard in binary disassembly and decompilation precision (via the Hex-Rays decompiler). By connecting IDA Pro to an MCP server via **IDAPython**, AI agents can interact with IDA databases (`.idb` / `.i64`), trigger Hex-Rays decompilations, manipulate local types, and perform pattern matching across game binaries.

---

## 🚀 1. Architecture & Installation

```
+-------------------+     JSON-RPC     +--------------------+     IDAPython IPC     +----------------------+
|     AI Agent      | <==============> |    IDA MCP Server  | <===================> |   IDA Pro Instance   |
| (Claude / Codex)  |      (stdio)     |  (FastMCP / Node)  |       (Socket)        |  (Hex-Rays Decompiler|
+-------------------+                  +--------------------+                       +----------------------+
```

### Installation Steps

1. **Install IDAPython Bridge**:
   Deploy the Python MCP server script inside your IDA user plugins directory:
   - Windows: `%APPDATA%\Hex-Rays\IDA Pro\plugins\ida_mcp_service.py`
   - Linux/macOS: `~/.idapro/plugins/ida_mcp_service.py`

2. **Configure MCP Server**:
   ```json
   {
     "mcpServers": {
       "ida-pro": {
         "command": "python",
         "args": ["C:/Tools/ida-mcp/server.py", "--host", "127.0.0.1", "--port", "13337"]
       }
     }
   }
   ```

## 🛠️ 2. Core IDA MCP Tools

### `ida_decompile`
- **Description**: Invokes the Hex-Rays decompiler on a function specified by address or name.
- **Parameters**: `address: str`, `flags: int` (optional).
- **Output**: Clean C pseudocode generated by Hex-Rays.

### `ida_get_struct` / `ida_set_struct_member`
- **Description**: Queries or defines structured types directly in IDA's Local Types window.
- **Parameters**: `struct_name: str`, `offset: int`, `type: str`, `name: str`.

### `ida_find_pattern`
- **Description**: Executes binary pattern / signature search (byte sequences with wildcards like `55 8B EC 83 EC ??`).
- **Output**: Array of matching virtual addresses.

### `ida_set_name`
- **Description**: Renames an address or global variable in the IDA project.

## 🔄 3. Hex-Rays Microcode & Deep Type Analysis

Hex-Rays exposes an intermediate representation (Microcode) that can be queried through MCP:
1. **Microcode Optimization**: AI agents can inspect microcode instructions (`m_call`, `m_ldx`, `m_stx`) before decompilation heuristics to detect obfuscation or inlined subroutines.
2. **Type Propagation**: Setting a struct definition on a pointer automatically cascades through all dereferences across the Hex-Rays AST.

---

## 💡 Best Practices

- **Sync Local Types (`til`)**: Ensure your IDA database has relevant type libraries loaded (e.g. `directx`, `win32`, `crt`) so Hex-Rays recognizes standard COM interfaces and Win32 APIs automatically.
- **Batch Processing**: Use headless IDA (`idat.exe` / `idat64.exe` with `-A -S`) for autonomous multi-binary analysis.
